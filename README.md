# Bushcraft Is Life

Simulador interactivo para armar un kit de bushcraft desarrollado como proyecto final de JavaScript.

## Funcionalidades

- Carga dinámica de productos desde JSON mediante Fetch
- Agregado y eliminación de productos
- Cálculo automático del total
- Finalización del kit
- Notificaciones con Toastify
- Diseño responsive

## Tecnologías

HTML, CSS, JavaScript, Fetch API, JSON y Toastify.
